## 使い方

1. このファイルを編集して、各セルの文字数制限やAIへの指示をカスタマイズします
2. プロンプトを再生成します:
   ```bash
   python -m portfolio.generate_portfolio_v2 --generate-prompts --verbose
   ```
3. 更新されたプロンプトファイル（`docs/portfolio-prompts/*.md`）を確認します
4. 生成されたプロンプトファイルを使って、`.cursor/portfolio-generated-content.json`を作成します
5. Excelファイルを生成します:
   ```bash
   python -m portfolio.generate_portfolio_v2 --from-json .cursor/portfolio-generated-content.json
   ```

## 注意事項

- このファイルはオプショナルです。存在しなくてもシステムは正常に動作します
- 最大文字数のオーバーライドは、設定ファイル（`.cursor/portfolio_config.json`）の`max_chars`より優先されます
- AIへの指示は、プロンプトファイルの「ユーザーからの追加指示（このセル固有）」セクションに反映されます
- セル名は設定ファイルの`cell_mapping`のキーと完全に一致している必要があります
