このリポジトリは、Excelベースのポートフォリオ（職務経歴ポートフォリオなど）を自動生成するためのツールです。

## 概要
- **目的**: 各プロジェクト固有の設定ファイル・テンプレートをもとに、ポートフォリオ用の Excel ファイルを自動生成する。
- **想定ユースケース**: 開発プロジェクトの紹介資料や、個人の職務経歴ポートフォリオの自動生成など。

## 大まかなワークフロー
1. **プロンプト生成フェーズ**
   - `.cursor/portfolio_config.json` と `docs/portfolio-user-settings.md` をもとに、セルごとのプロンプトファイル（Markdown）が生成されます。
   - コードベースのコンテキストや Git 履歴なども、必要に応じてプロンプトに含める想定です。
2. **AI による内容生成フェーズ**
   - 生成されたプロンプトを AI（例: Cursor AI）に読み込ませ、各セルに対応する文章・内容を生成します。
   - 生成結果は `.cursor/portfolio-generated-content.json` のような JSON に保存します。
3. **Excel 出力フェーズ**
   - Excel テンプレート（例: `ポートフォリオ_Template_sample.xlsx`）をコピーし、JSON に保存された内容を各セルに書き込みます。
   - 将来的にはテンプレートなしで、まっさらなブックから必要なシート・セル構造を生成することも視野に入れています。
